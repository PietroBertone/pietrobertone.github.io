Jannik privacy policy

Last updated: 30 September 2026.

Jannik is a personal tool with exactly one user, its owner. It does not serve anyone else.

What Google data Jannik uses

With the owner's consent, Jannik uses one Google permission, https://www.googleapis.com/auth/calendar.events, to create and delete calendar events for the owner's own tennis court reservations on the owner's own Google Calendar. It reads only the events it created itself, which carry a private tag. It does not read, change or delete any other event.

Storage and sharing

The access token is stored only on machines the owner controls. No Google user data is sold, shared with third parties, used for advertising, or used to train AI models. Event invitations are sent only to the owner's own work address.

Jannik's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.

Contact

Use the developer contact email shown on Jannik's Google consent screen.
